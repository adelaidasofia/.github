# adelaidasofia .github

Org-wide GitHub config for [adelaidasofia](https://github.com/adelaidasofia).

Holds:
- Default issue templates
- Default pull-request templates
- Org-wide Dependabot defaults
- Workflow templates surfaced in the new-repo "starter" picker

Per-repo workflows live in their own repos. Security policies are enforced by `gh-harden-repos.sh` (ruleset + secret-scan + Dependabot + auto-merge per blast-radius tier + minimal CI for code repos).
